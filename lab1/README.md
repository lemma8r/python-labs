# Лабораторная работа №1. Биквадратное уравнение

**Дисциплина:** Парадигмы и конструкции языков программирования
**Преподаватель:** Лемехова М. П.

## Задание

Решить биквадратное уравнение вида:
a·x⁴ + b·x² + c = 0

где `a, b, c` — действительные числа, `a ≠ 0`.

Требуется найти **действительные** корни. Решение через замену `y = x²` сводится к квадратному уравнению `ay² + by + c = 0`.
