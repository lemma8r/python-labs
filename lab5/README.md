# Лабораторная работа №5. Модульное тестирование в Python

## Описание
Данная лабораторная работа посвящена изучению возможностей модульного тестирования в Python. В качестве основы был выбран код из лабораторной работы №1 (решение биквадратного уравнения).

## Что сделано
1. **Модификация кода:** Исходный код (`biquadratic.py`) был адаптирован для тестирования. Функция `solve_biquadratic()` сделана чистой (без ввода-вывода), а функция `get_coef()` получила параметры `argv` и `input_func` для внедрения зависимостей.
2. **TDD (Test-Driven Development):** Написан класс тестов `TestSolveBiquadratic` с использованием встроенного фреймворка `unittest` (6 тестов).
3. **Mock-объекты (доп. задание):** Написан класс тестов `TestGetCoefMock` с использованием `unittest.mock.Mock` для проверки логики чтения коэффициентов (3 теста).
4. **BDD (Behavior-Driven Development):** Написаны сценарии на языке Gherkin (`biquadratic.feature`) и шаги для фреймворка `behave`.

## Структура проекта
- `biquadratic.py` — Модифицированный код (модуль с логикой)
- `test_tdd.py` — TDD-тесты (unittest)
- `test_mock.py` — Mock-тесты (unittest.mock)
- `features/`
  - `biquadratic.feature` — BDD-сценарии (Gherkin)
  - `steps/`
    - `biquadratic_steps.py` — Реализация шагов для behave
- `README.md` — Этот файл

## Установка и запуск

### Требования
- Python 3.10+ (использовался Python 3.14)
- Установленный фреймворк `behave` (и его зависимости: `parse`, `parse-type`, `six`, `colorama`, `cucumber-expressions`, `cucumber-tag-expressions`).

### Подготовка окружения
Рекомендуется использовать виртуальное окружение. В папке `lab5` выполните:
python -m venv venv
venv\Scripts\activate      # Для Windows
# source venv/bin/activate # Для Linux/Mac
pip install behave

### Запуск тестов
Все команды выполняются из папки `lab5`.

**1. TDD-тесты:**
python -m unittest test_tdd -v

**2. Mock-тесты:**
python -m unittest test_mock -v

**3. BDD-сценарии:**
python -m behave

### Запуск самой программы
