# Лабораторная работа №3-4. Функциональные возможности языка Python
**Дисциплина:** Парадигмы и конструкции языков программирования
**Преподаватель:** Гапанюк Ю. Е.
## Задание
Лабораторная работа состоит из решения 7 задач, демонстрирующих возможности функционального программирования в Python: генераторы, итераторы, декораторы, контекстные менеджеры, а также использование функций `map`, `filter`, `zip` и `sorted`.
Все файлы с решениями расположены в пакете `lab_python_fp`. Каждая задача находится в отдельном файле.
## Структура проекта
* `lab_python_fp/`
  * `field.py` — Задача 1 (генератор field).
  * `gen_random.py` — Задача 2 (генератор случайных чисел).
  * `unique.py` — Задача 3 (итератор Unique для удаления дубликатов).
  * `sort.py` — Задача 4 (сортировка по модулю).
  * `print_result.py` — Задача 5 (декоратор print_result).
  * `cm_timer.py` — Задача 6 (контекстные менеджеры cm_timer_1 и cm_timer_2).
  * `process_data.py` — Задача 7 (комплексная обработка данных).
* `data_light.json` — файл с данными для Задачи 7.
## Примечание к Задаче 7
Оригинальный файл `data_light.json` содержит более 16 000 строк с вакансиями. При его обработке вывод программы переполняет буфер терминала, из-за чего результаты функций `f1`-`f3` становятся недоступны для просмотра.
Для того чтобы продемонстрировать работу всех функций (и получить наглядный результат для отчета), **в репозиторий загружен тестовый фрагмент файла из 10 записей. В начало фрагмента были искусственно добавлены три записи с вакансиями программистов** (разный регистр и уровни). Это позволяет функции `f2` (фильтрация) и `f3` (модификация) отработать корректно.
Сама программа `process_data.py` является полностью рабочей и предназначена для обработки исходного полного файла.
## Запуск
Для запуска любой задачи из корневой папки `lab3-4` используйте:
`py lab_python_fp/<имя_файла>.py`
Для Задачи 7 из-за относительных импортов используется команда:
`py -m lab_python_fp.process_data`
