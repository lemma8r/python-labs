# Лабораторная работа №2. ООП в Python

**Дисциплина:** Парадигмы и конструкции языков программирования
**Преподаватель:** Гапанюк Ю. Е.

## Задание
Разработать консольное приложение на Python 3 с использованием классов для вычисления площади геометрических фигур (прямоугольник, квадрат, круг) с применением абстрактных классов и свойств. Также необходимо использовать внешний пакет, установленный через pip.

## Структура проекта
*   `main.py` — основной файл для тестирования классов.
*   `lab_python_oop/` — пакет с классами фигур:
    *   `figure.py` — абстрактный класс Figure.
    *   `color.py` — класс Color.
    *   `rectangle.py` — класс Rectangle.
    *   `square.py` — класс Square.
    *   `circle.py` — класс Circle.

## Установка и запуск
1. Создано виртуальное окружение: `py -m venv venv`
2. Активация (Windows): `.\venv\Scripts\activate`
3. Внешний пакет `prettytable` (и его зависимость `wcwidth`) установлены локально из файлов `.whl` из-за блокировки PyPI провайдером.
4. Запуск программы: `python main.py`

## Результат работы
Программа создает три фигуры (Прямоугольник, Круг, Квадрат), выводит их параметры через метод `__repr__` и дополнительно выводит их характеристики в виде красивой таблицы с помощью пакета `prettytable`.
